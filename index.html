neo does the work

neo is the assistant built into the panel. Tell it what you want and it acts on your server instead of explaining how.

What it does

  • Installs plugins, mods and modpacks, and switches server software.
  • Reads the logs and fixes what crashed.
  • Manages files, the console, power, backups and startup settings.
  • Creates new servers and resizes existing ones.

You approve the risky parts

Deleting a server, spending tokens and restoring a backup always wait for your approval. For everything else, you choose whether neo asks first or just does it.

Free to use

neo costs nothing. Fair-use limits apply, counted over a 5-hour window and a weekly window.

What you can run

Pick one when you create a server and the panel installs it. Game servers get their own port; Node.js and Python are there for bots, APIs and anything else you write yourself.

Minecraft: Java Edition

Purpur for plugins, or Fabric, Forge and NeoForge for mods and modpacks. A setup wizard asks which one you want, and neo can switch it later.

Minecraft: Bedrock

The official Bedrock dedicated server, for players on consoles, phones and Windows.

Velocity

A Minecraft proxy: put it in front of several servers and move players between them without a reconnect.

FiveM / RedM

CFX roleplay servers. They get a second port automatically, so txAdmin runs alongside the server.

Multi Theft Auto

An MTA server, the multiplayer mod for Grand Theft Auto: San Andreas.

Node.js

A general-purpose runtime for Discord bots, web APIs and anything else that starts from a package.json.

Python

A general-purpose runtime for bots, scrapers and small services, with your dependencies installed when it starts.

Log check

One place for the whole lifecycle

Everything below lives behind one sign-in at panel.plugged.host.

Console and power

Start, stop, restart or kill a server and watch its output live, with CPU, memory and disk usage next to the console.

Files, in the browser or over SFTP

Edit configuration in place, upload a world or a build, unpack archives on the server and pull files from a URL. When the browser is the wrong tool, connect over SFTP.

Databases and ports

Up to five MariaDB databases and five ports per server, with credentials as soon as you create them.

Backups and schedules

Five backups per server to restore or download. Downloads stream from backups.plugged.host, with no wait for an archive to be built. Schedules restart, back up or send a command on a timer.

Moving servers

Move a server to another location yourself and follow the progress live. Failed steps are retried on their own, and if the move fails, the server starts again where it was.

People and accountability

Invite subusers with only the permissions they need. Every action lands in an activity log, so a shared server stays answerable.

Credits, tokens and locations

Two currencies, each with its own store in the panel.

Credits

Earned by inviting friends to the plugged.host Discord server, by boosting it, and in giveaways. Spend them in the Resource Store on more CPU, memory and disk.

Tokens

Earned from optional sponsored links and a free daily token. Spend them in the Token Store on start-queue priority and on Plus and Premium locations.

Locations

Free locations are open to every account. Plus and Premium locations are unlocked once, with tokens.

We publish the bad days too

Live status, uptime and incidents are public at status.plugged.host.

  • Checked every minute

    The panel checks the website, itself and every node once a minute and publishes the result.

  • Usage as numbers

    CPU, memory and storage are published per node. A node at 90% or more of any of them is reported as degraded, automatically.

  • Incidents on the record

    Open incidents override component status, and every update stays visible afterwards, also over RSS.

  • Nothing private

    The public feed carries node names and metrics only. Hostnames and addresses never leave the panel.

Straight answers

Is it really free?

Yes. plugged.host costs nothing today and is paid for by ads: the panel shows them, and starting a server can show one first unless you hold a priority pass bought with tokens. Capacity is finite, so allocations can be adjusted or reclaimed to keep the fleet healthy. If paid plans ever arrive, they will come with their own terms, shown before you buy.

How do I sign in?

With a noprofit.space account, at accounts.noprofit.space: a password, a passkey, an authenticator app or Discord. An existing plugged.host account moves over the first time you sign in and keeps its credits. Cloudflare Turnstile protects sign-in and registration, and you accept the current Terms and Privacy Policy.

Can I run something that isn't on the list?

Often, yes. The Node.js and Python images are general-purpose, so most things you can start from a repository in either language will run inside your allocation. Mining cryptocurrency and similarly heavy computation need our written permission first; the Acceptable Use Policy lists what is off-limits.

Are my backups safe?

You get five backups per server and can restore or download any of them, and downloads from backups.plugged.host start right away. Treat them as a convenience rather than an archive: keep your own copy of anything you would hate to lose. The Terms say the same.

Who runs this, and where do I get help?

plugged.host is run by noprofit.space from Paris, France. Help is in our Discord server; keep passwords and personal data out of public channels. Legal questions go to legal@noprofit.space and privacy requests to privacy@noprofit.space.

Host what you build.

Create an account, pick a game or a runtime, and the panel sets the server up. Questions go to the Discord, where someone is usually around.
