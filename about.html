About plugged.host

Free hosting for game servers, bots and small services, run by noprofit.space from Paris, France.

What plugged.host is

plugged.host gives anyone a free place to run a game server or a small program that has to stay online. Everything happens in one control panel at panel.plugged.host: you create a server, watch its console, edit its files, take backups and invite friends to help run it.

The panel installs Minecraft: Java Edition, Minecraft: Bedrock, the Velocity proxy, FiveM and RedM, and Multi Theft Auto for you. Its Node.js and Python runtimes are general-purpose, so Discord bots, web APIs and your own small services run there too. neo, the assistant built into the panel, can do most of the work for you: install a modpack, read a crash log and fix it, or set up a new server.

Who runs it

plugged.host is a service of noprofit.space, based in Paris, France. You sign in with a noprofit.space account, which you manage at accounts.noprofit.space. noprofit.space publishes the Terms and the Privacy Policy that cover plugged.host.

Help happens in the open, in our Discord server, where the people who run the service and other server owners answer questions. The Contact page lists where everything else goes.

How it is paid for

plugged.host costs nothing and takes no payments. It is paid for by advertising: the panel shows ads, starting a server can show one first, and Minecraft servers show a short in-game message about once an hour. We do not sell personal data.

Two things let you go further without paying:

  • Credits come from inviting friends to the Discord server, boosting it and giveaways. They buy more CPU, memory and disk for your account.
  • Tokens come from optional sponsored links in the panel. They pay for plugged.host Plus, which removes the in-game ads and gives you priority when a node is busy, and its add-on PlusPlus, which removes every ad.

How we run it

A budget you can read before you sign up
Every account gets one pool of CPU, memory and disk to spread across as many servers as it likes. The numbers are on the home page, and the resources guide explains how they work.
Status in public
The website, the panel and every node are checked once a minute, and the results, incidents included, are published at status.plugged.host.
You stay in control
neo asks before it deletes a server, spends your tokens or restores a backup. Everything you and your subusers do lands in each server's activity log.
Fair use for everyone
The nodes are shared, so servers are checked for cryptocurrency miners, attack tools and similar abuse, which the Acceptable Use Policy forbids. A node that gets too busy stops taking new servers until it has room again, so the servers already on it keep running smoothly.
