Back up, restore and schedule

Backups protect your server from a bad update, a broken mod or a griefer. Schedules make them happen without you.

Updated 12 October 2026

Create a backup

  1. Open Backups in your server's menu.
  2. Choose Create Backup.
  3. Give it a name you will recognise later, like before 1.21 update.
  4. Optionally, list files and folders to leave out under Ignored Files & Directories, such as logs or a cache folder, to keep it small.
  5. Tick Locked? if this backup must never be removed by accident or by a schedule.

Each server keeps up to five backups. When it has five, delete one before you create another. You can create two backups every ten minutes.

Restore a backup

Choose Restore on the backup. The server stops, and while the restore runs you can't start it, use the file manager or create other backups. Tick Delete all files before restoring backup? to get the server exactly as it was; leave it unticked to put the backup's files back over the current ones and keep any files the backup doesn't have.

Restoring overwrites what's on the server now. If you might want the current state back, take a backup of it first.

Download and the off-site copy

Download on a backup saves it to your computer as an archive. Above the list, the Off-site copy card shows the copy of your server that plugged.host keeps on separate storage, which you can download right away from backups.plugged.host without waiting for an archive to be built. Sign in there with your plugged.host account or with Discord to see your servers.

Backups are a convenience, not an archive. Keep your own copy of anything you can't afford to lose, as the Terms also say.

Lock what matters

Lock protects a backup until you Unlock it. A locked backup can't be deleted, and scheduled backups skip it when they make room. Lock the backup of a world you are proud of before trying something risky.

Schedules

A schedule runs tasks at set times. Open Schedules, create one and choose when it runs: pick Hourly, Daily, Weekly or Monthly, or fill in the minute, hour, day of month, month and day of week yourself, like a cron job. Times are in UTC.

Then add up to ten tasks, each with an optional Time Offset after the one before:

  • Send Command: a console command, such as say Restarting in 5 minutes.
  • Send Power Action: start, stop, restart or kill the server.
  • Create Backup: a new backup. When the server already has five, the oldest unlocked one is replaced.
  • Delete Files: remove files, such as old logs.

Only when Server is Online? skips the schedule while the server is off, and Enable Schedule? pauses it without deleting it.

Example: a nightly backup with a warning

  1. A daily schedule at 04:00 UTC.
  2. Task 1: Send Command say Backup in 1 minute, expect a little lag.
  3. Task 2, 60 seconds later: Create Backup.

With five slots and a nightly backup, you always have the last five days to go back to. Lock one now and then to keep a snapshot for longer.
