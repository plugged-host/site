Guides

Step-by-step help for running servers on plugged.host, from your first Minecraft world to a Discord bot that stays online.

Minecraft

Create a free Minecraft Java serverFrom an empty account to friends on your server: create it, run the setup wizard and share the address. Install plugins, mods and modpacksBrowse Modrinth, CurseForge and SpigotMC from the panel, install in one click, and update or remove what's already there. Let Bedrock players join your Java serverOne click adds Geyser and Floodgate, so players on phones, consoles and Windows join your Java server. Upload, download or create a Minecraft worldBring a singleplayer world to your server, download it, switch worlds, or start fresh with your own seed. Give your server its own addressSwap host-and-port addresses for a name like play.onplugged.host that players can remember. Build a Minecraft network with VelocityPut a Velocity proxy in front of a lobby and game servers so players move between them without reconnecting. Run a Minecraft Bedrock serverThe official Bedrock dedicated server for players on phones, tablets and Windows.

Other games

Set up a FiveM or RedM server with txAdminCreate the server, open txAdmin on its second port, add your license key and invite players.

Bots and apps

Host a Discord bot with Node.jsUpload or clone your bot, keep its token out of the code, and run it without your own computer. Host a Discord bot with PythonRun a discord.py bot with its requirements.txt, a .env file for the token and the Python version you need.

Using the panel

Connect to your server over SFTPFind your SFTP details and connect with FileZilla, WinSCP or Cyberduck to move many or large files. Back up, restore and scheduleCreate, lock, download and restore backups, and let schedules back up and restart your server for you. Create a database for your serverA MariaDB database for plugins, FiveM frameworks and bots, with its credentials one click away. Move your server to another locationMove a server closer to your players yourself. Files, worlds and backups come along. Get things done with neoAsk the assistant in the panel to install, fix and configure your servers, and decide what it may do without asking. Share a server with friendsAdd subusers with only the permissions they need, and see who did what in the activity log.
