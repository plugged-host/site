Install plugins, mods and modpacks

The panel searches Modrinth, CurseForge and SpigotMC for you and installs the right file for your server's software and version.

Updated 12 October 2026

Plugins or mods?

It depends on the software you chose in the setup wizard:

  • Plugins run on Paper, Spigot and Purpur servers. They change the game on the server only, so players join with a normal Minecraft client. Good for permissions, economies, minigames, protection and anti-grief.
  • Mods run on Fabric, Forge and NeoForge. Many add blocks, items and worlds that players need too, so they install the same mods (or the same modpack) on their side. Server-side mods, such as performance mods, need nothing on the player's side.

Your server's page is called Plugins or Mods & Modpacks to match. To switch software later, ask neo or install a modpack, which sets the right loader for you.

Find and install

  1. Open Plugins (or Mods & Modpacks) in the server's menu.
  2. Search, and narrow the list with the Source (Modrinth, CurseForge, and on plugin servers SpigotMC), Type and Minecraft version filters. Results already match your server's software.
  3. Choose 1-Click Install for the newest compatible version, or Versions to pick a specific one.
  4. Restart the server. Plugins and mods load at start-up.

Many plugins and mods depend on others, such as a library or an API. Read the project's page (the View on link in each row) and install what it lists.

Modpacks

On a Fabric, Forge or NeoForge server, search for modpacks and choose Install. The panel switches the server to the modpack's loader and Minecraft version, installs its mods and keeps your world. Your players install the same modpack, at the same version, in their launcher: the Modrinth App, the CurseForge app or Prism Launcher all work.

Take a backup before you install or change a modpack. A world that has been played with mods may not load without them.

What's installed

Under Installed on this server, the panel lists every jar in your plugins or mods folder, including ones you uploaded yourself, and works out what each one is: by its file hash, its CurseForge fingerprint, its name or the information inside the jar. For each one you can:

  • Update it to the newest compatible version.
  • Disable it without deleting it, which is handy when you are hunting for the plugin that breaks something. Enable brings it back.
  • Delete it, and if you want, the folder with its configuration too.

Uploaded a jar over SFTP? Choose Rescan to see it in the list.

When the server won't start after a change

  1. Open the console and look for the first error; the log check above the console often names the culprit.
  2. Disable the plugin or mod you added last and start again.
  3. Check that it is built for your Minecraft version and loader. A Forge mod won't load on Fabric, and a mod for 1.20.1 won't load on 1.21.
  4. Still stuck? Ask neo to fix it: it reads the log, finds the mod and can disable or replace it for you.
