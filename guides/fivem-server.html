Set up a FiveM or RedM server with txAdmin

plugged.host installs the CFX server for you and gives txAdmin a port of its own, so you finish the setup in your browser.

Updated 12 October 2026

Before you start

  • A Cfx.re account. You use it to sign in to txAdmin and to create the server license key every FiveM and RedM server needs.
  • A plugged.host account. You sign in with a noprofit.space account; the first sign-in creates it.

1. Create the server

  1. In the panel, choose Create server, give it a name and pick FiveM/RedM under Game.
  2. Pick a location and a plan. A roleplay server with a framework and a few dozen resources wants at least Standard (two CPU threads, 4 GB of memory, 20 GB of disk); large frameworks need more.
  3. Choose Deploy server.

The panel gives a FiveM/RedM server two ports automatically: the game port, and the port right after it for the txAdmin web interface. Both are listed on the server's Network page. The Address on the Console, such as de1.plugged.host:30120, is the host name and the game port; the txAdmin port is also set as txAdmin port on the Startup page. Leave that value as it is: it has to match the second port.

2. Open txAdmin

  1. Press Start and watch the console. On the first start, txAdmin prints a PIN.
  2. Open http://<host name>:<txAdmin port> in your browser: the host name from the Address on the Console, followed by the second port.
  3. Enter the PIN, link your Cfx.re account and set a backup password for txAdmin.

The PIN only works once. If someone else could have seen it, restart the server to get a new one before you link your account.

3. Run the setup wizard

  1. Name your server.
  2. Choose how to deploy it. A recipe, such as the default CFX server, QBCore or ESX for FiveM, or one of the RedM recipes, downloads a working base for you. If you already have a server, choose your existing files instead.
  3. When txAdmin asks for a license key, create one at portal.cfx.re under Server Keys and paste it in. Keep the key private: anyone with it can run a server under your name.
  4. If the recipe needs a database, create one in the panel first (see the databases guide) and give txAdmin its host, name, user and password.
  5. Let txAdmin finish, then start the server from its dashboard.

From then on, txAdmin manages the server: restarts, players, bans, resources and the live console. The panel's start and stop buttons start and stop txAdmin itself.

4. Let players connect

Players open FiveM (or RedM), press F8 and type connect followed by the Address from the Console, for example connect de1.plugged.host:30120. That is the game port, not the txAdmin one. Once your server is listed in the server browser, they can also find it by name.

Updating the server

The FiveM Version variable on the Startup page decides which server build the installer downloads: recommended (the default, and the safe choice) or latest. Update resources and frameworks from txAdmin or over SFTP, and take a backup first.

When something goes wrong

txAdmin doesn't load in the browser
Check that you used the second port and http://, not https://, and that the server is running.
Players see "server is not responding"
They are probably using the txAdmin port. The game port is the first one on the Network page.
The server stops during start-up
Read the txAdmin console: a missing or invalid license key and a resource that fails to load are the usual causes. You can also ask neo in the panel to look at the console with you.
