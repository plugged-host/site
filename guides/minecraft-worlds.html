Upload, download or create a Minecraft world

The Worlds page handles everything about your Minecraft Java server's world: bring one from singleplayer, keep a copy, or start a new one with the seed you want.

Updated 12 October 2026

The Worlds page

Open Worlds in your Minecraft server's menu. Each world on the server has a card with its seed, world type, difficulty, game mode, whether structures are generated, and when it was last saved. The world the server loads is the one in use; the others stay on disk until you switch to them or delete them.

Uploading, replacing and generating worlds need the server to be off. The page offers Stop server when it is running.

Upload a singleplayer world

  1. On your computer, find the world folder. In the Minecraft launcher, it is in the saves folder of your game directory: on Windows, %appdata%\.minecraft\saves.
  2. Compress that world's folder into a .zip (or .tar.gz). The folder that contains level.dat should be at the top of the archive.
  3. On the Worlds page, choose Upload a world, pick the archive and choose Upload and replace.
  4. Start the server and join it.

The upload limit is 100 MB on most nodes. For a bigger world, upload the folder over SFTP into the server and then choose Use this world on its card.

A world from a newer Minecraft version won't open on an older server. Upgrading works the other way, but take a backup first: once a world is converted to a newer version, it can't go back.

Download a world

Choose Download on the world's card. The panel packs it into a .zip and gives you a link that stays valid for two hours. Unpack it into your saves folder to play it in singleplayer. To keep regular copies without doing anything, set up scheduled backups.

Create a new world

For a fresh start with a random seed, choose Generate on the current world. For more control, choose Options:

World name
The folder the new world is saved in. A new name keeps the old world on disk.
Seed
Leave it on Random, or paste a seed you found online or in singleplayer.
World type
normal, flat (superflat), large_biomes, amplified (extreme mountains, heavier to run) or single_biome_surface. Generator settings customises flat and single-biome worlds.
Generate structures
Villages, temples, strongholds and the rest. Turn it off for a clean flat build world.
Data packs
The data packs the world starts with.
Keep a copy of the current world
Leave this on unless you are sure you don't need the old world any more.

Choose Create new world. The world is generated the next time the server starts, so the first start takes a little longer.

Switch or remove worlds

Use this world makes the server load another world on its next start. Files opens the world's folder in the file manager, and Delete removes a world you no longer need, which frees disk space in your account's pool.
