Connect to your server over SFTP

The file manager in the panel is fine for a few files. For a large world, a modpack or a whole project, connect with an SFTP client instead.

Updated 12 October 2026

Find your connection details

Open your server's Settings and find SFTP Information:

Connection
The host name and port, for example de1.plugged.host:2022. Copy Host copies it. Note that the port is not 22.
Username
Your panel username, a dot and the server's short ID, for example steve.1a2b3c4d. Each server has its own, so you always land in the right one. Copy Username copies it.
Password
Your noprofit.space account password, the one you sign in to the panel with. There is no separate SFTP password. If you only ever sign in with Discord or a passkey, add a password to your account at accounts.noprofit.space first.

Launch in SFTP Client opens the connection in the SFTP program installed on your computer, if your system knows one.

Connect with FileZilla

  1. Install FileZilla (the client, not the server).
  2. Open File › Site Manager › New site.
  3. Set Protocol to SFTP - SSH File Transfer Protocol.
  4. Fill in Host (without the port), Port 2022 or the one shown, Logon Type Normal, then your User and Password.
  5. Choose Connect. The first time, FileZilla asks you to trust the server's key; accept it.

Your server's files appear on the right. Drag files between your computer on the left and the server.

Other clients

  • WinSCP (Windows): choose SFTP as the file protocol and fill in the same four fields.
  • Cyberduck (macOS and Windows): Open Connection, choose SFTP, and enter the host, port, username and password.
  • Command line: sftp -P 2022 steve.1a2b3c4d@de1.plugged.host, with your own port, username and host.

Tips

  • Stop a Minecraft server before you replace its world or a mod, so it doesn't overwrite your upload when it saves.
  • Upload one archive and unpack it in the panel's file manager, rather than thousands of small files. It is much faster.
  • Everything you upload counts towards the server's disk space.
  • Subusers connect with their own username and password, and only if you gave them the SFTP permission. See Share a server with friends.

When it doesn't connect

Authentication failed
Check that the username includes the dot and the server ID, and that the password is your current account password. Copy both from the panel to avoid typos.
Connection refused or timed out
Check the port: SFTP uses the port shown in the panel, not 22 or the game port. Make sure the protocol is SFTP, not FTP or FTPS.
