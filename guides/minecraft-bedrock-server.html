Run a Minecraft Bedrock server

The Bedrock dedicated server is Mojang's own server for Minecraft: Bedrock Edition, the version on phones, tablets, Windows and consoles.

Updated 12 October 2026

Bedrock server or Java with Geyser?

A Bedrock server plays exactly like Bedrock Edition: Bedrock redstone, add-ons and marketplace-style behaviour packs. Java players can't join it. If your group mixes both editions, run a Java server with Bedrock support instead.

1. Create the server

  1. In the panel, choose Create server and pick Vanilla Bedrock under Game.
  2. Pick a location close to your players and a plan. Starter runs a small world for a few friends; give it more memory for more players or a large world.
  3. Choose Deploy server. The panel downloads the latest Bedrock server.

2. Set it up

On the server's Startup page you can change:

  • Server Name: the name players see in their server list.
  • Gamemode and Difficulty.
  • Allow cheats, for commands such as /give and /time.
  • Choose World: the world folder the server loads.
  • Bedrock Version: latest keeps up with the game. Bedrock clients update themselves, and a server on an older version turns them away.

Restart the server after a change. Everything else is in server.properties in the Files.

3. Invite players

  1. Copy the Address from the server's console. It is a host name and a port, for example de1.plugged.host:30125.
  2. In Minecraft, players open Play › Servers › Add Server, type the host name as the address and the number after the colon as the port.

On Xbox, PlayStation and Nintendo Switch, the game has no Add Server button. Players there usually join through a phone or PC friend, or with a helper app such as BedrockTogether.

Allowlist and operators

To keep the server private, set allow-list=true in server.properties, restart, and add players from the console with allowlist add PlayerName. Make someone an operator with op PlayerName. Commands in the console go without the slash.

Bring your own world

Stop the server, then upload your world folder into the worlds folder with the file manager or SFTP. On Windows, singleplayer Bedrock worlds are in the game's minecraftWorlds folder. Set Choose World to the folder name and start the server. Take a backup before you replace a world you have played on.
