Give your server its own address

Instead of an address like de1.plugged.host:30123, players can join with a name you choose, such as play.onplugged.host, and no port at all.

Updated 12 October 2026

What you get

A subdomain is a name under onplugged.host that points at your server. For Minecraft: Java Edition, it also carries the port, so players type only the name. It follows the server around: if you move the server to another location, the subdomain updates itself and players keep using the same name.

Subdomains are available for Minecraft: Java Edition and FiveM/RedM servers.

Before you start

  • Link your Discord account to your noprofit.space account at accounts.noprofit.space, and join the plugged.host Discord server. Subdomains are a perk for members of the server.
  • Have some tokens. A subdomain takes a small token deposit, which grows with each extra subdomain on the same server. Tokens come from the Tokens page in the panel.

Create one

  1. Open Subdomains in your server's menu.
  2. Choose Create Subdomain.
  3. Type a name, for example play or the name of your community. Letters, numbers and hyphens work best. A few names are reserved, such as minecraft, mc and plugged.
  4. Save. The Connect With column shows what players type.

New names usually work within a few minutes. If a player's game still can't find it, they can wait a little longer or restart the game, which clears its cached lookup.

A server can have up to three subdomains, for example one for your community name and one short one.

How players join

  • Java Edition: Multiplayer › Add Server, then the subdomain alone, such as play.onplugged.host.
  • Bedrock players on a Java server with Geyser: the subdomain as the address and the Geyser port as the port.
  • FiveM/RedM: connect followed by the subdomain and the game port.
