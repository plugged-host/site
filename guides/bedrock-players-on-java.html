Let Bedrock players join your Java server

Geyser translates between Bedrock Edition and Java Edition, so players on phones, tablets, consoles and Windows can play on your Java server with everyone else.

Updated 12 October 2026

How it works

Geyser runs inside your server and listens on a second port for Bedrock players. Floodgate lets those players join with their Microsoft account, without owning Java Edition. plugged.host installs both for you, gives Geyser its own port and writes it into Geyser's configuration.

It works on servers running the Vanilla / Paper / Spigot / Purpur software, Fabric or NeoForge. Forge is not supported.

Turn it on

When you create a server, the setup wizard asks about Bedrock support: choose Yes, add Bedrock support.

On an existing server:

  1. Open Plugins (or Mods & Modpacks) in the server's menu.
  2. Choose Add Bedrock support at the top and confirm.
  3. The panel downloads Geyser and Floodgate, reserves a port for Bedrock players and restarts the server. Bedrock players can connect once it is back up.

The same button reads Update Geyser once it is installed. Update it when a new Minecraft version comes out: Bedrock clients update themselves, and an old Geyser turns them away.

How Bedrock players join

  1. Open the server's Network page and find the port marked Geyser (Bedrock).
  2. In Minecraft (Bedrock Edition), players open Play › Servers › Add Server.
  3. For the server address, they type the host name from the server's Address, such as de1.plugged.host, without the Java port. For the port, they type the Geyser port.

If you gave the server its own onplugged.host name, Bedrock players can use that name as the address, with the Geyser port.

On Xbox, PlayStation and Nintendo Switch, the game only shows the featured servers and has no Add Server button. Players there usually join through a phone or PC friend's world, or with a third-party helper app such as BedrockTogether.

Things to know

  • Bedrock players get a . in front of their name (for example .Steve), so they never clash with a Java player of the same name. Use that name for the whitelist and for operator commands.
  • Some Java-only features look different or are missing on Bedrock: custom items, some resource packs, and mods that add new blocks. A plain or plugin server works best.
  • Plugins that check the player's client version, and some anti-cheats, need a Geyser-compatible setting. Check their documentation if Bedrock players are kicked.
