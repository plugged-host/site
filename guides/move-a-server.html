Move your server to another location

Players far away, or a location that is often busy? Move the server yourself, with its files, worlds and backups, and follow the move live.

Updated 28 October 2026

Before you move

  • Pick the location closest to most of your players; distance matters more than anything else for lag.
  • Free locations are open to every account. Plus locations need plugged.host Plus or Premium, and Premium locations need Premium.
  • A server can't move while it is installing, restoring a backup or making one, or while it is suspended. A server can move once every six hours.

Move it

  1. In your server's menu, expand More and choose Transfer.
  2. Choose Pick a location and select where it should go. A location without room for your server's size is marked as full.
  3. Read the summary, which says roughly how long the server will be offline, and confirm with Move to followed by the location.

The server stops, its files are copied to the new location, and it starts again there. The page shows each step as it happens. Bigger servers take longer: the copy is the slow part.

What changes

  • The address. The server gets a new host name and port. Share the new Address from the console with your players.
  • Subdomains update themselves, so if your players use a name like play.onplugged.host, nothing changes for them.
  • Ports in the server's settings, such as the txAdmin port of a FiveM server or Geyser's Bedrock port, follow the new numbers.
  • Files, worlds, backups, schedules, subusers and databases stay with the server.

If something goes wrong

A failed step is retried by itself, on another node in the same location if needed. The old copy is only removed after the new one has been checked, so a move that can't finish leaves the server where it was, and it starts again there. While a move is running you can still choose Cancel move.

Who can move a server: the owner, and subusers who have the Transfer permission.
