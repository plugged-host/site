Create a free Minecraft Java server

Create a Minecraft: Java Edition server, pick its software and version in the setup wizard, and share the address with your friends. It takes a few minutes.

Updated 12 October 2026

1. Create the server

  1. Sign in at panel.plugged.host with your noprofit.space account (the first sign-in creates it) and choose Create server.
  2. Under Details, type a server name, or press the dice button for a random one.
  3. Under Game, pick Minecraft: Java Edition.
  4. Under Location, pick the country closest to your players. Free locations are open to everyone; Plus and Premium locations need plugged.host Plus or PlusPlus. A location marked Full has no room right now.
  5. Under Resources, pick a plan. See below for how much a server needs.
  6. Leave the box that accepts the Minecraft EULA ticked (a server can't run without it) and choose Deploy server.

The panel opens the server's console and shows Setting up your server while it installs. That takes a minute or two.

How much memory does it need?

Every account has one pool of CPU, memory and disk to share between its servers, so a smaller server leaves room for others. As a rough guide:

  • Starter (2 GB of memory): a few friends on a plain or lightly modded server.
  • Standard or Pro (4 to 8 GB): a group of 10 to 20 players, plugins, or a small modpack.
  • Ultimate and up (12 GB or more): large modpacks or a busy public server.

You can resize the server later, so start small and grow it if it struggles. The resources guide explains the pool.

2. Run the setup wizard

When the install is done, the panel asks you to Set up your server before anything else:

Server software
Vanilla / Paper / Spigot / Purpur runs plugins and plays like vanilla Minecraft; it installs Purpur, a fast fork of Paper that runs Paper, Spigot and Bukkit plugins. Fabric, NeoForge and Forge run mods. Pick a mod loader only if you want mods: players then need the same mods installed too.
Minecraft version
Latest (recommended), or an older version if your players or your mods need one.
Modpack
For a mod loader, you can search Modrinth and install a whole modpack, or keep No modpack - just the plain server.
Bedrock support
Choose Yes, add Bedrock support to let players on phones, consoles and Windows join too. The crossplay guide explains how it works.
Player accounts
Premium accounts only checks every player with Mojang, so nobody can join under someone else's name. Keep it unless you know you need the other option.
Who is it for
Private - friends only turns on the whitelist, so only the players you list can join. Public - anyone can join leaves it open.
Players
Type the Minecraft names of your Allowed players and of your Operators, the players who can use admin commands.

Choose Finish setup. The server starts with your settings.

3. Invite your friends

The Address on the server's console, for example de1.plugged.host:30123, is what players type to join. Click it to copy it. In Minecraft, they open Multiplayer, choose Add Server and paste it, port included.

Want something easier to remember? You can give the server a name like play-yourname.onplugged.host, with no port to type: see Give your server its own address.

4. Look after it

  • The console shows the server's output live and takes commands, without the slash: op Steve, whitelist add Alex, say Restarting in 5 minutes.
  • The log check on the console page reads the server log for you. When it finds a problem, it says what is wrong and offers Ask neo to fix it.
  • Backups protect your world from mistakes and griefing. Take one before you add mods or update; the backups guide shows how to automate them.
  • Plugins and mods install from the panel; see Install plugins, mods and modpacks.

Free servers show a short message in the game chat about once an hour, "This server is powered by plugged.host". plugged.host Plus turns it off.
