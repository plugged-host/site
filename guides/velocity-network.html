Build a Minecraft network with Velocity

Velocity sits in front of several Minecraft servers, so players join one address and move between a lobby, survival and minigames without reconnecting.

Updated 12 October 2026

What you need

  • One Velocity server: the proxy players connect to. It needs little memory; Starter is plenty for a small network.
  • Two or more Minecraft: Java Edition servers behind it, set up with the Vanilla / Paper / Spigot / Purpur software. These are your lobby and game servers.

All of them share your account's resource pool. Create them in the same location: every hop between the proxy and a game server adds delay.

1. Create the servers

  1. Create a server with Velocity as the game. Its install generates a forwarding.secret file, which the game servers use to trust it.
  2. Create the game servers and run their setup wizard. Note each one's Address from its console, for example de1.plugged.host:30123.

2. Point Velocity at your servers

In the Velocity server's Files, open velocity.toml and set:

player-info-forwarding-mode = "modern"

[servers]
lobby = "de1.plugged.host:30123"
survival = "de1.plugged.host:30124"
try = ["lobby"]

[forced-hosts]

Use your own addresses, and clear the example entries under [forced-hosts] that refer to servers you don't have. try lists where players land when they join.

3. Make the game servers trust the proxy

On every game server:

  1. In server.properties, set online-mode=false. The proxy checks players' accounts instead.
  2. In config/paper-global.yml, under proxies › velocity, set enabled: true, online-mode: true and secret: to the contents of Velocity's forwarding.secret.
  3. Restart the server.

With modern forwarding on, a game server turns away anyone who tries to join it directly instead of through the proxy, so online-mode=false doesn't open a back door.

4. Join

Start Velocity and the game servers, then give players the Velocity server's address. They land in the lobby; /server survival moves them, and plugins on the proxy or a lobby menu can do the same.

When it doesn't work

"Unable to connect you to lobby"
Check the address and port in velocity.toml and that the game server is running.
"This server requires you to connect with Velocity" when using the proxy
The secrets don't match, or player-info-forwarding-mode isn't modern. Copy forwarding.secret again, with no extra spaces.
Skins missing or players get new UUIDs
Forwarding is off on that game server. Recheck paper-global.yml.
